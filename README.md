## 📌 About The Project

**RoomieSpot** is an Android-based room and flat rental application designed to simplify the process of finding affordable accommodation.

Finding a suitable room or flat in a new city can be difficult, especially for students and working professionals. RoomieSpot provides a convenient platform where users can explore available rental properties, view property details, save their favourite listings, and directly contact property owners.

The application aims to make the rental experience easier, faster, and more accessible.

## ✨ Key Features

- 🔐 **User Authentication** – Secure login and registration.
- 🏠 **Property Listings** – Explore available rooms and flats.
- ➕ **Add Property** – Allow users to publish rental properties.
- 📍 **Property Details** – View rent, location, description, and images.
- ❤️ **Favorites** – Save properties for future reference.
- 📞 **Direct Contact** – Contact property owners easily.
- 💬 **WhatsApp Integration** – Connect with owners through WhatsApp.
- 🔄 **Real-time Database** – Store and retrieve property information using Firebase.
- 🎨 **User-Friendly Interface** – Simple and intuitive Android UI.
- 📱 **Navigation System** – Easy navigation using drawer and bottom navigation.

## ⚙️ Installation & Setup

Follow these steps to run RoomieSpot locally.

**1. Clone the repository**

```bash
git clone https://github.com/Harsh6465/RoomieSpot.git
```

**2. Open in Android Studio**

- Open Android Studio.
- Select Open Project.
- Choose the cloned RoomieSpot folder.
- Wait for Gradle synchronization.

**3. Configure Firebase**

- Create a project in Firebase Console.
- Register your Android application.
- Add your `google-services.json` file inside the app directory.
- Enable the required Firebase Authentication and Realtime Database services.

**4. Run the Application**

- Connect an Android device or start an emulator.
- Click the Run button in Android Studio.
- Explore RoomieSpot!
